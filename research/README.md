- **Federation is Local Subjects + Typed Relations, not a Global Run**;
- **Shared Work != Shared Run != Shared Context**;
- **Operational Subject Identity != Infrastructure Identity**;
- **Delegation != Authority Copy != Truth-Owner Transfer**;
- **Delivery != Admission != Adoption != Cognition**;

- **Cross-Subject Accountability Requires Explicit Evidence Adoption/Binding**;

- **Shared Ancestry != Federation Convergence**;
