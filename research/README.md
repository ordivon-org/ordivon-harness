## Campaign 3 — current theory

P3' replaces one global Effect state with evidence-relative standing over explicit bounded **Realization Claims Q**:

1. Evidence Projection Validity;
2. Dispatch Standing;
3. Realization Claim Contract/scope;
4. Realization Evidence Standing for Q;
5. use-relative Reconciliation/Settlement;
6. downstream Continuation/Redispatch Obligation.

Provisional laws:

- **Realization Standing is Claim-Scope and Evidence Relative**;
- **Dispatch Standing != Realization Claim Standing**;
- **No Receipt != No Effect != Retry Permission**;
- **Local Terminality != External Causal Finality != Semantic Success**;
- **Partial Realization is Scoped Mixed Claim Standing**;
- **Invocation Cardinality != External Realization Cardinality**;
- **Compensation != Prior Effect Erasure**;
- **Reconciliation Settlement is Use-Relative and History-Preserving**.

Round 2 directly supports the bounded implementation subset: preparation != receipt, terminal/nonterminal lineage, reconciliation without history rewrite, result-content retention separation, response-loss redispatch fencing, fresh-process settled/pending distinction, dispatch ambiguity, and durable-failure standing preservation.

Partial/delayed/compensating/interfering world effects remain conceptual/future-evidence cases; they are not claimed as engineering-proven.
