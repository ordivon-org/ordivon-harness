# Ordivon Harness Research — Agent Operational Mediation

This directory is the canonical navigation surface for the materialized Harness research project. Harness is studied here as **Agent Operational Mediation**: the boundary-relative structures by which an Agent receives externally grounded state, forms bounded operational context and intent, invokes external realization, attributes evidence/effects/results, and preserves operational identity without annexing external truth.

This research root does **not** replace product `README.md` / `ARCHITECTURE.md`, and current engineering contracts do not define the research ontology.

## Selected first post-Constitution campaign

**Operational Identity Under Failure — Run Identity & Recovery Equivalence** was selected by typed tournament rather than a scalar score. It pairs Run Identity with Recovery because recovery requires a same-operation criterion while failure/recovery supplies the strongest destructive test of that criterion.

Rich Effect Semantics, Context Equivalence, Multi-Agent mediation and Accountability remain separate frontiers. Campaign 1 may use narrow uncertain-effect or Context-change fixtures but may not annex those full theories.
