## 5. Tournament result

**SELECTED CAMPAIGN 6:**

# Federated Operational Identity
## Delegation, Context Transfer, Shared Effects & Cross-Agent Accountability

This title deliberately avoids “Multi-Agent Coordination” as the primitive. The campaign should first determine the semantics of multiple bounded operational subjects and their relations before claiming a general coordination theory.

### Bounded purpose

Derive and destructively test a technology-neutral Harness criterion for federating multiple Agent-facing operational subjects while preserving local Run identity, explicit delegation/authority, Context/evidence transfer, shared/duplicate effect standing, and cross-Agent accountability.

### Explicit non-goals

Campaign 6 will not:

- create one global group-mind Context;
- create one universal global Run spanning all Agents;
- define general distributed consensus;
- define Network partition/reachability truth;
- define normative legitimacy of delegation;
- define Human team/social organization;
- treat message delivery as evidence of cognition/adoption;
- claim direct multi-Agent engineering proof from adjacent single-Harness fixtures;
- create HaF62.

## 6. Required destructive dimensions

Campaign 6 Charter must prebind at least:

- two local Runs under one durable Host Task;
- delegation without full authority transfer;
- authority attenuation vs amplification;
- Context sent but not adopted;
- evidence adopted with exact provenance;
- same evidence visible to two Agents but different Effective Contexts;
- two Agents invoke the same external capability and duplicate realization risk emerges;
- one Agent sees terminal receipt while another remains underdetermined;
- shared realization claim but different evidence standing;
- Agent A CompletionProposal does not complete Agent B or Host Task;
- one Agent's OCSS evidence reused by another without adoption/binding;
- contradictory Agent claims with common-cause evidence;
- partitioned continuation yielding two successor branches;
- later federation reconciliation preserving branch history;
- delegation revoked after downstream Agent has already acted;
- process/channel identity changes without Agent operational identity change;
- Agent identity changes while process/channel remains the same;
- moved/split cut evaluated using OPUR rather than assumed equivalent.
