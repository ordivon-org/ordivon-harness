# 40 — CROSS-OWNER BRIDGES

This map records where Harness research consumes or mediates another owner's facts. A bridge is not owner reassignment.

## Host

Canonical boundary:

- Host: durable Host Task continuity + Host Journal/CAS/fencing/handoff authority.
- Harness: bounded Agent Run / TaskEpisode / Context / Invocation / control mediation.
- Persistent purposive coordination: derived / cross-owner reality.
- `CompletionProposal != Host Task completion`.

Relevant HaFs include 12,16,34,38,40,46,48–50,52–53,58–61. These links do not collapse Host Task into Harness TaskEpisode or RunEpisode.

## Ordivon Normative

HaF11,12,31,34,38–43,47,49 use authority/governance/obligation/process vocabulary. Harness may carry typed externally grounded authority, permission, commitment, procedure and remedy state; it does not generate normative legitimacy, entitlement, fairness, obligation correctness, remedy correctness or normative finality.

## Runtime

Runtime owns Workspace/Job/Attempt/process and physical execution truth. Harness owns Run-level intent, control/effect mediation, Invocation lineage, result attribution and continuity objects at the Harness cut.

Relevant HaFs include 6,8,14–19,24,36,37,48,54,55,58–61.

## Network

Network owns cross-locus capability/transport/path/service structure and forwarding/reachability realization. Harness consumes network facts when coordinating distributed/federated operation.

Relevant HaFs include 18–21,26,40,46,56,59–61.

## Human

Human owns human-native cognition, motivation, perception/phenomenology and social-human structures. Harness owns only externalized interaction/control/evidence mediation.

HaF13/14 explicitly consumed Human HF18/HF19; HaF26,41,44,45,46,50 also have strong Human-facing bridges.

## World / Reality and specialist domains

World/Reality and specialist domain owners supply target-world/domain truth, causal facts, measurement referents, success criteria, institutional facts and acceptance conditions where applicable. Harness observation/evidence/result objects remain scoped mediation claims over those facts.

## SCD / Computational Possibility and other Computing owners

When a Harness implementation carries computational descriptions, semantic contracts, applicability assumptions or computational-possibility claims, those semantic/computability truths remain with the corresponding Computing owner. Harness may expose, bind, invoke or record them without becoming the semantics owner.

## Bridge invariant

A HaF may be deletion-essential for the Harness mediation layer while still depending on an external owner's truth. Foundation standing inside Harness therefore does not imply primitive ownership of every noun appearing in its title.
